# Auto Order Store
Website auto-order modular yang siap di-upload ke GitHub Pages.

## Struktur
- `index.html` — halaman utama
- `products.html` — katalog produk
- `checkout/` — halaman checkout
- `orders/` — halaman status/order
- `admin/` — dashboard admin demo
- `data/products.json` — data produk
- `assets/css/` — stylesheet
- `assets/js/` — JavaScript
- `components/` — komponen UI
- `config/` — konfigurasi toko
- `api/` — tempat integrasi backend/API

## Catatan
Versi ini memakai localStorage untuk demo. Untuk order online sungguhan, sambungkan backend/database dan payment gateway.
